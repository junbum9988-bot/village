# 학생별 에셋 폴더

학생 한 명당 하나의 번호 폴더(`01` ~ `18`)를 사용합니다. 번호는 학생 출석번호(또는 지정 번호)와 맞춰서 관리하세요.

```
assets/students/
  01/
  02/
  ...
  18/
```

각 번호 폴더 안에는 다음 두 하위 폴더를 둡니다:

```
assets/students/01/
  original/   # 원본 이미지 (변환/가공 전)
  items/      # 그 학생이 실제로 쓰는 아이템 이미지 (원본을 다듬거나 변환한 결과물)
```

- `original/`: 업로드된 원본 이미지를 그대로 보관하는 곳. 나중에 다시 가공해야 할 때 원본을 잃지 않기 위함입니다.
- `items/`: 게임에서 실제로 아이템으로 사용하는 이미지. `js/main.js`의 `ITEM_CATALOG` 같은 곳에서 참조하게 됩니다.

두 폴더 모두 이미지가 채워지기 전까지는 비어 있으므로 `.gitkeep`으로 Git에 폴더 자체가 유지되게 해뒀습니다.
(이미지를 자동으로 `original/` → `items/`로 변환하는 기능과, 아이템 목록을 `items.json`으로 관리하는 기능은
아직 구현되지 않았고 이후 단계에서 추가될 예정입니다.)

폴더 이름은 항상 두 자리 숫자(`01`, `02`, ..., `18`)로 통일해 정렬과 코드에서의 참조가 어긋나지 않도록 합니다.
학생 수가 늘어나면 같은 규칙으로 `19`, `20` ... 폴더를 추가하면 됩니다.

관리자용 에셋은 `assets/admin/`을 참고하세요 (같은 `original/` / `items/` 구조).

이 폴더(그리고 `assets/admin/`)는 **첫 번째 마을**(village-1, 접속 코드 T00/S01~S18) 전용입니다.
두 번째 마을(village-2, 접속 코드 B00~B18) 에셋은 서로 섞이지 않도록 `assets/village2/`라는
별도 폴더에 있습니다 - 자세한 내용은 `assets/village2/README.md` 참고.
