# 관리자용 에셋 폴더

학생 개인 소유가 아닌, 관리자(교사)가 관리하는 이미지를 위한 폴더입니다. 구조는 학생 폴더와 동일합니다.

```
assets/admin/
  original/   # 원본 이미지 (변환/가공 전)
  items/      # 실제로 쓰는 아이템 이미지 (원본을 다듬거나 변환한 결과물)
```

두 폴더 모두 이미지가 채워지기 전까지는 비어 있으므로 `.gitkeep`으로 Git에 폴더 자체가 유지되게 해뒀습니다.

학생별 에셋 규칙은 [assets/students/README.md](../students/README.md)를 참고하세요.
