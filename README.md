# 우리 반 마을 꾸미기

초등학생들이 각자의 공간(방)을 꾸미고, 다른 학생의 공간을 탐험할 수 있는 2D 마을 꾸미기 웹게임입니다.

## 기술 구성

- HTML / CSS / JavaScript (프레임워크 없이 순수 웹 표준으로 시작)
- 추후 Supabase 연동 예정 (학생별 데이터 저장/불러오기)
- Cloudflare Pages 배포 예정 (정적 사이트 그대로 배포 가능)
- 모바일 / 태블릿 / PC 반응형 대응

## 폴더 구조

```
index.html          앱 진입점 HTML
css/
  style.css          전체 스타일 (반응형 포함)
js/
  main.js            앱 초기화 스크립트 (추후 모듈 분리 예정)
assets/
  students/           학생별 이미지 에셋
    01/ ~ 18/           학생 번호별 폴더
  common/             모든 학생이 공유하는 공통 에셋
```

학생별 에셋 관리 규칙은 [assets/students/README.md](assets/students/README.md)를 참고하세요.

## 현재 상태

기본 프로젝트 구조만 생성된 단계입니다. 게임 로직, 화면 전환, 아이템 배치, 데이터 저장 등은 아직 구현되어 있지 않습니다.

## 로컬에서 열어보기

빌드 과정이 없는 순수 정적 사이트이므로 `index.html`을 브라우저로 열거나, 간단한 정적 서버로 실행하면 됩니다.

```bash
npx serve .
```
